# 🧬 Эволючий Эпох

**Эволючий Эпох** — это игра, где игроки проходят путь развития, от человека с дубиной до солдата с оружием. Проект специально оптимизирован для работы в браузере (WebGL), управлению ресурсами и производительности в Unity.

## 🛠 Использованные технологии

Проект построен с упором на масштабируемость, высокую производительность и оптимизацию под WebGL:

- **Unity & C#**
- **Zenject (Extenject)** — внедрение зависимостей (DI) для создания слабосвязанной и легко тестируемой архитектуры.
- **UniTask** — высокопроизводительная асинхронность, заменяющая стандартные корутины для более чистого, быстрого и безопасного кода.
- **DOTween** — анимация UI
- **Unity Addressables** — система адресной загрузки ресурсов для оптимизации использования памяти и ускорения начальной загрузки WebGL-билда.
- **Unity Editor** — создание дополнительного инструментария

## ✅ Проделанная работа

1. **Архитектура и код:**
   - Спроектирована и реализована модульная архитектура на базе Zenject.
   - Асинхронные операции (загрузка сцен, инициализация систем, работа с данными) переведены на UniTask с корректной обработкой ошибок и отменой операций.
2. **Оптимизация производительности:**
   - Внедрен пул объектов для часто создаваемых и уничтожаемых сущностей, что значительно снизило нагрузку на Garbage Collector и предотвратило микрофризы.
   - Проведена глубокая оптимизация через Unity Profiler: уменьшен размер итогового WebGL-билда и повышена стабильность FPS.
   - Настроена загрузка ресурсов через Addressables для эффективного управления памятью в браузере.
3. **Дополнительные инструменты:**
   - Создание конфигов для однотипных уровней с разными объектами
   - Автопостроение уровня
   - Автонастройка юнитов (вражеских/игрока)
